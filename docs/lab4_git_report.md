# Звіт до лабораторної 4. Git у терміналі

**Виконав:** Нюкін Сергій, ІПЗ-3/2

1. **Що змінилося у виводі `git status` після `git add`?** Файл `index.html` перейшов зі списку Untracked у Changes to be committed, тобто потрапив в індекс і буде збережений наступним commit-ом; решта файлів лишилась невідстежуваною.
2. **Що показує `git diff`?** Різницю між робочою копією та останнім збереженим станом: рядки з `+` додані, з `-` видалені (у мене додався абзац «TaskBoard допоможе керувати завданнями команди»).
3. **Чим відрізняється `git switch main` від `git merge`?** `git switch main` лише переходить на гілку main, змінюючи файли робочої копії під її стан; `git merge about-page` вливає зміни іншої гілки в поточну (у мене це було fast-forward злиття).
4. **Чому виник конфлікт і як я його розв'язав?** У гілках `main` і `ukr-title` по-різному змінено той самий рядок `<h1>`, і Git не зміг вибрати автоматично. Я прибрав службові рядки `<<<<<<<`, `=======`, `>>>>>>>` і поєднав обидва варіанти: `<h1>Дошка завдань: керуй завданнями</h1>`, потім `git add` і commit.
5. **Скільки commit-ів в історії?** Разом із цим звітом — 8. Вивід `git log --oneline` перед фінальним commit-ом:
