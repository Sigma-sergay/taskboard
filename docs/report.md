# Звіт до лабораторних робіт з веб-технологій

**Виконав:** Нюкін Сергій, ІПЗ-3/2

## Лабораторна 5. GitHub, README та старт проєкту TaskBoard

- Створено публічний репозиторій `taskboard` на GitHub.
- Проєкт має структуру: `index.html`, `about.html`, `images/`, `docs/`, `.gitignore`, `README.md`.
- Оформлено `README.md` у форматі Markdown: заголовки, таблиця технологій, список плану розвитку, посилання на демо.
- Увімкнено GitHub Pages (гілка `main`, корінь репозиторію).
- Зміни в `about.html` внесено через окрему гілку `update-about` і Pull Request, який злито в `main`.

### Що я зрозумів

1. `git push` відправляє локальні commit-и у віддалений репозиторій (origin), а `git pull` забирає чужі зміни.
2. README — «обличчя» проєкту: з нього людина одразу бачить, що це за проєкт, як його запустити і де подивитися демо.
3. GitHub Pages безкоштовно публікує статичний сайт прямо з гілки репозиторію.
4. Pull Request дає змогу переглянути різницю (Files changed) перед злиттям гілки — так працюють у команді.
